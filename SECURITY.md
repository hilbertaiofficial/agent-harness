# Security Policy

This repository may discuss agent security, prompt injection, tool misuse, authorization failures, and data exfiltration risks.

Please do not publish live credentials, private data, working exploit chains against real third-party systems, or instructions that enable immediate abuse.

## Reporting

For sensitive security concerns, open a private report with the maintainers or contact Hilbert AI through the official website. Public issues are appropriate for taxonomy discussion, benchmark design, and non-sensitive examples.
